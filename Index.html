FALO Source Inbox Frontend

This HTML file is now treated as an external frontend artifact. It is not deployed inside GAS.

Current role

  • Acts as the portable frontend source file.
  • Can later be hosted from local files, GitHub Pages, or another static environment.
  • Should call the GAS backend through HTTP API instead of google.script.run.

Current backend expectation

  • Backend endpoint is the deployed GAS web app URL.
  • Requests should use JSON payloads shaped like { action, params }.
  • Google Sheet and Drive remain the runtime data layer.

Next build step

Once the GAS backend is deployed, this file can be expanded into a real external frontend that performs login, source CRUD, attachment linking, and send-to-self actions through fetch-based API calls.
